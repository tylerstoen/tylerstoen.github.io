Discovering Differentially Correlated Sets Across Multiple Treatments

Statistical Methodology · Unsupervised Methods · R

My master’s thesis, introducing a new Variable Set Affinity Testing (VSAT) method for more than three treatments. My contribution generalizes the existing method of Differential Correlation Mining to three or more treatment conditions identifying sets of variables whose correlation structure differs across multiple conditions. The full thesis is available on Cal Poly Digital Commons.

Microorganism Diversity in Vineyard Soil

Unsupervised Methods · R

My capstone project, working for client Dr. Katie Watts of the Cal Poly Chemistry department under the supervision of Dr. Kelly Bodwin and Dr. Alex Dekhtyar. I analyzed local vineyard soil to identify drivers of microbial diversity using differential correlation.

NBA General Manager Hypothetical

Scala · Spark

Using Scala and Spark, I analyzed NBA player data to make hypothetical off-season roster decisions in hindsight, as if I were a general manager. By examining team weaknesses and roster gaps heading into the next season, I evaluated which players would add the most value.

Plastic Waste

R · Dashboard · Package Development

An end-to-end analysis of global plastic waste. The report pairs with an interactive dashboard and an R package bundling the data and reusable analysis functions.

GeoLife Trajectories

R · MCMC · K-means

Modeled GPS movement data as a Markov chain over spatial regions to determine long-run behavior of individuals in the region of interest. Instead of a typical grid split to define transitions as north, south, east and west, the region was split using k-means on uniquely visited locations and assigning points to the nearest centroid with Voronoi polygons.

Cockroach Neurons

R · Poisson Processes

Modeled neural spike trains as non-homogeneous Poisson processes to test whether citronellal odor puffs change the firing rate of cockroach antennal lobe neurons.

Breast Cancer Detection

Python · sklearn

Classification of Kaggle breast cancer data as malignant or benign using various classification methods including K-Nearest Neighbors, Support Vector Machine and Random Forest.

Image Classification

Python · sklearn

A fun image classification project predicting a photo’s photographer, one of two professors for a class. The project consisted of three stages: fitting a pretrained EfficientNet (transfer learning), hand-labeling images and using a standard scikit-learn classifier, and finally ensembling both into a final classifier.
